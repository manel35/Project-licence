# Welcome

## Project Overview

Code Tracker is a Smart Code Tracking Platform designed and developed to help users track their coding progress, analyze performance, and improve their programming skills.

The application includes an interactive dashboard that allows users to monitor their activity, visualize statistics, and manage their progress efficiently.

---

## How to Run the Project

To run this project locally, follow these steps:

### 1. Clone the repository
git clone <GIT_URL>

### 2. Navigate to the project folder
cd code-tracker

### 3. Install dependencies
npm install

### 4. Run the project
npm run dev

The application will start on a local development server and can be accessed via your browser.
